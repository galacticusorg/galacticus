# Galacticus tutorials

Jupyter notebooks, committed with their executed output.

- [`library/`](library/) — the Galacticus Python library interface (`libgalacticus`): the physics engine of Galacticus
  called directly from Python.
- [`models/`](models/) — running Galacticus models and analyzing their output with
  [dendros](https://github.com/galacticusorg/dendros).

Tutorials driven by parameter files alone are in the
[user guide](https://galacticus.readthedocs.io/en/latest/manuals/user-guide/tutorials/index.html), with their
parameter files in `parameters/tutorials/`.
