Notebook tutorials
==================

Executed Jupyter notebooks. Each is committed with its executed output, kept up to date by continuous integration, so
the results shown are real.

Python library
--------------

Notebooks introducing the Galacticus Python library interface — the physics engine of Galacticus exposed to Python
through the ``libgalacticus`` shared library. To run them yourself, see the `library tutorials README
<https://github.com/galacticusorg/galacticus/tree/master/tutorials/library>`_ for how to obtain the library.
